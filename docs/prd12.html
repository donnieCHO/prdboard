0.1 화면 문구 지침

  • 초등학생이 바로 읽을 수 있는 쉬운 말만 쓴다. 「업로드」「로그인 실패」 대신 「사진 넣기」「비밀번호가 달라요」처럼 쓴다.
  • 화면 글자는 한 줄로 보이게 짧게 쓴다.
  • 틀렸을 때는 다그치지 않고 부드럽게 안내한다(예: 「비밀번호가 달라요. 다시 해 봐요」).
  • 막힐 때는 무엇을 하면 되는지 한 문장으로 말한다(예: 「인터넷이 안 돼요. 다시 해 봐요」, 「선생님께 말씀드려요」).
  • 선생님이 남긴 글은 「코멘트」, 독후감에 찍는 표시는 「칭찬 도장」, 다시 쓰게 하는 것은 「고쳐쓰기 요청」으로 부른다.

1. 문제 정의와 교육적 근거

1.1 해결하려는 문제

  • 그림책 교환독서를 Padlet 같은 범용 게시판으로 하면, 책마다 슬라이드를 따로 만들어야 하고 활동 통제가 어렵다.
  • 범용 게시판은 링크만 있으면 학교 밖 누구나 볼 수 있어서, 그림책 쪽 사진이 외부로 퍼질 위험이 있다.
  • 범용 도구는 버튼·문구가 많고 작아서, 초등 저학년이나 글이 서투른 학생이 혼자 쓰기 힘들다.
  • 선생님은 수업 중 학생이 어느 쪽을 읽고 무엇을 붙였는지 한눈에 보기 어렵다.
  • 독후감은 종이나 다른 도구로 따로 받아서, 읽기 활동과 독후감·피드백이 이어지지 않는다.

1.2 교수·학습 가설

  • 학생이 그림책 쪽 위에 직접 반응을 붙이면, 내용과 자기 생각을 더 구체적으로 잇는다.
  • 글, 녹음, 그림, 사진 중 고를 수 있으면 읽기·쓰기 수준이 다른 학생도 모두 참여한다.
  • 친구의 반응과 독후감을 읽는 교환독서는 읽기 동기와 다양한 관점을 키운다.
  • 선생님의 짧은 코멘트, 칭찬 도장, 고쳐쓰기 요청은 글쓰기 과정에서 바로 도움이 된다.

1.3 제품 원칙(우선순위 순)

  1. 학생이 혼자 쓴다. 큰 버튼, 짧은 문구, 숫자 4자리 비밀번호로 도움 없이 들어가고 활동한다.
  2. 그림책은 학교 안에만 둔다. 그림책 저작권을 지키려고 접근벽을 세운다. 선생님이 허가한 학생만 들어오고, 관리자가 만든 우리 학교 학급 사이에서만 책을 나눈다(11.1).
  3. 모두 참여한다. 글이 어려운 학생은 녹음·그림으로, 코멘트는 음성(TTS)으로 들을 수 있다.
  4. 내 것만 고친다. 학생은 본인 카드·독후감만 고치고, 선생님은 모두 고칠 수 있다.
  5. 선생님이 보고 공개한다. 독후감은 선생님이 확인해야 반 친구에게 보인다.
  6. 한 화면에 담는다. 스크롤 없이 쪽 넘김으로, 화면 글자는 한 줄로.

2. 사용자

2.1 1차 사용자

초등학생과 담임·교과 선생님. 학생은 개인 아이패드를 쓰고, 글을 읽고 쓰는 정도가 서로 다르다. 선생님은 수업 중 학생 활동을 보고 돕기를 원한다.

5.3 UI·접근성 원칙

  • 아이패드 가로 1180×820 기준 무대를 기기 크기에 맞게 줄인다.
  • 스크롤 없이 한 화면에 담는다. 예외는 선생님 홈 그림책 탭과 그림책 추가 화면.
  • 버튼은 손가락으로 누르기 쉬운 크기(주요 버튼 높이 48px 안팎).
  • 화면 글자는 한 줄로 보인다.
  • 글자 입력 중 화면이 확대되거나 밀리지 않게 하고, 입력이 끝나면 제자리로 돌린다.
  • 선생님 코멘트는 스피커 버튼으로 들을 수 있다(TTS).

6. 기능 요구사항

FR-01. 학급 입장 [P0]

  • 인트로에서 학급 코드를 한 번 입력하면 기기에 저장된다.
  • 선생님이 코드를 바꾸면 저장된 코드는 풀리고 「코드가 바뀌었어요. 새 코드를 써요」를 보여 준다.
  • 학생은 큰 버튼, 선생님은 작은 버튼, 관리자는 오른쪽 위 「관리자 모드」로 들어간다.

FR-02. 학생 로그인·가입 [P0]

  • 이름을 고르고 숫자 4자리 비밀번호를 누른다. 기기는 마지막 이름을 기억하고, 비밀번호는 매번 입력한다.
  • 비밀번호가 없는 학생은 처음 들어올 때 두 번 눌러 정한다.
  • 이름이 없는 학생은 이름과 비밀번호로 가입하고, 선생님이 승인해야 들어간다. 같은 이름이 있으면 가입할 수 없다.
  • 틀리면 부드러운 안내창만 뜨고 다시 누를 수 있다.

FR-03. 책장 [P0]

  • 표지와 제목이 함께 보이는 책장에서 책을 고른다. 다 읽은 책에는 표시가 붙는다.
  • 책을 다시 열면 마지막으로 본 쪽에서 시작한다.

FR-04. 책 읽기와 활동 카드 [P0]

  • 스크롤 없이 쪽을 넘긴다. 쪽마다 선생님의 질문 카드가 보인다.
  • 말풍선·쪽지·도형·사진·영상·녹음 카드를 붙인다. 말풍선·쪽지는 모양과 색을 고른다. 학생이 만든 카드는 빈 카드로 시작한다.
  • 카드를 한 번 누르면 선택, 한 번 더 누르면 글자 입력이다. 쪽지는 안쪽 어디를 눌러도 입력된다.
  • 선택한 카드는 손가락으로 옮기고, 모서리 버튼으로 크기를 바꾸고 지운다.
  • 학생은 본인 카드만 고친다. 질문 카드는 옮기지 못한다.

FR-05. 앞으로·뒤로 보내기 [P0]

  • 카드를 선택하면 카드 아래(아래 공간이 없으면 위)에 「앞으로」「뒤로」 버튼이 뜬다.
  • 겹친 카드끼리 한 칸씩 순서를 바꾼다. 더 갈 곳이 없으면 버튼이 흐려진다.
  • 학생은 본인 카드만, 선생님은 모든 카드를 바꾼다. 글자 입력·끌기 중에는 버튼을 숨긴다.

FR-06. 선택 해제 [P0]

  • 카드 밖 빈 곳을 누르면 선택 테두리, 지우기·크기 버튼, 앞으로·뒤로 버튼이 함께 사라진다.
  • 글자를 입력하던 중이면 글자를 저장하고 해제한다.
  • 다른 카드, 버튼, 아래 도구 막대를 누르면 해제되지 않는다. 학생 화면과 실시간 화면 보기에 모두 적용한다.

FR-07. 코멘트와 음성 [P0]

  • 선생님은 실시간 화면에서 학생 카드에 글 코멘트를 남기고 크기를 바꾼다.
  • 학생 화면에서는 코멘트 옆 스피커 버튼으로 음성(TTS)을 듣는다.

FR-08. 독후감 쓰기 [P0]

  • 마지막 쪽의 「다 읽었어요」에서 이어진다. 다섯 가지 방식(4.3) 중 하나를 고른다.
  • 쓰다 말면 임시로 저장되고, 제출하면 완료 화면을 거쳐 책장으로 돌아간다.

FR-09. 독후감 확인·공개 [P0]

  • 선생님은 독후감 탭에서 제출된 독후감을 읽고 칭찬 도장을 찍는다.
  • 「고쳐쓰기 요청」을 피드백과 함께 보내거나 요청을 취소한다. 학생 글을 직접 고칠 수도 있다.
  • 공개한 독후감만 친구 독후감에 보인다.

FR-10. 내 독후감·친구 독후감 [P0]

  • 「내 독후감 모음」 카드에 칭찬 도장이 보이고, 고쳐쓰기 요청을 받은 카드에만 「고쳐쓰기 요청」 칩이 붙는다.
  • 독후감을 열면 피드백이 보이고, 요청받은 독후감은 같은 화면에서 바로 고친다.
  • 「친구 독후감」에서 반 친구의 공개 독후감을 책별로 읽는다.

FR-11. 실시간 화면 보기 [P0]

  • 선생님이 그림책을 열면 학생 활동이 뜨는 책 화면과 오른쪽 학생 상태 열이 보인다.
  • 학생 상태 열은 접속 여부와 읽는 쪽을 보여 준다. 10명까지 한 줄, 11~16명 두 줄, 17명 이상은 더 작은 두 줄. 학급 인원은 최대 20명을 고려한다.
  • 학생을 누르면 그 학생의 카드를 강조해 본다.
  • 「쪽 모아보기」는 모든 쪽을 격자로 보여 주고, 누른 쪽으로 바로 간다.
  • 「새로고침」은 학생 활동을 다시 불러온다.

FR-12. 현재 페이지로 부르기 [P0]

  • 「현재 페이지로 부르기」를 누르면 화면이 어두워지고 접속 중인 학생이 파랑게 표시된다.
  • 「모두 부르기」나 학생 한 명을 눌러 선생님이 보는 쪽으로 부른다. 학생 화면은 입력·창을 닫고 그 쪽으로 넘어간다.
  • 부른 뒤 학생 상태는 「N쪽 읽는 중」으로 바뀌고, 「부르기 끝내기」나 어두운 바탕을 눌러 끝낸다.

FR-13. 그림책 관리 [P0]

  • 쪽 사진을 여러 장 한 번에 올리고, 끌어서 순서를 바꾼다. 쪽마다 질문 카드를 넣는다.
  • 책을 고치거나 지우고, 학급에 열지 정한다.
  • 학교 책장에 공개하고, 다른 학급이 공개한 책을 우리 학급으로 가져온다.

FR-14. 학생·학급 관리 [P0]

  • 학생 이름을 추가·삭제하고 비밀번호를 정한다. 가입 대기 학생을 한 명씩 또는 모두 승인하거나 거절한다.
  • 학급 코드와 선생님 비밀번호를 바꾼다.

FR-15. 관리자 모드 [P1]

  • 학급 목록을 보고 학급을 만든다. 학급 코드는 관리자가 직접 입력하고, 새 선생님 처음 비밀번호는 임시로 정해진다. 만든 뒤 코드·비밀번호를 안내창으로 보여 준다.
  • 선생님 비밀번호를 초기화하고, 관리자 비밀번호를 바꾼다.

7. 상태 모델

7.1 학생 계정

(스스로 가입) → 승인 대기 ──승인──► 승인됨
                     └──────거절──► (삭제)
(선생님이 추가) → 승인됨(비밀번호 없음) ──처음 로그인에서 두 번 입력──► 비밀번호 있음

7.2 활동 카드(화면)

선택 안 됨 ──누름──► 선택됨(테두리·지우기·크기·앞으로/뒤로)
선택됨 ──한 번 더 누름──► 글자 입력 중(앞으로/뒤로 숨김)
글자 입력 중 ──다른 곳 누름──► 글자 저장
선택됨 ──빈 곳 누름──► 선택 안 됨

7.3 독후감

쓰는 중(임시 저장) ──제출──► 제출됨
제출됨 ──고쳐쓰기 요청──► 고쳐쓰기 요청됨 ──학생이 고쳐 제출──► 제출됨
                          └──요청 취소──► 제출됨
제출됨 ──공개──► 공개됨(친구 독후감에 보임) ──공개 취소 또는 학생이 고침──► 제출됨
칭찬 도장은 상태와 상관없이 따로 찍는다

7.4 현재 페이지로 부르기

평소 ──부르기 시작──► 부르기 중(어두운 바탕) ──모두 부르기──► 평소
                     │                         └─한 명 부르기──► 부르기 중 유지
                     └──끝내기·바탕 누름──► 평소
학생: 호출 번호가 커지면 입력·창을 닫고 부른 쪽으로 이동

11. 개인정보와 학교 현장 운영 원칙

  • 학생 정보는 이름(또는 별칭)과 비밀번호 해시만 받는다. 생년월일·연락처는 받지 않는다.
  • 학생 사진·영상·녹음은 같은 학급 안에서만 보인다. 얼굴이 나오는 사진은 찍지 않도록 수업에서 안내한다.
  • 독후감은 선생님이 공개한 것만 같은 학급 친구에게 보인다.
  • 학교 책장으로 나누는 것은 그림책 쪽·질문뿐이고, 학생 활동은 나누지 않는다.
  • 학급 코드가 알려졌다면 선생님이 코드를 바꾼다. 바꾸면 기기에 저장된 옛 코드는 풀린다.
  • 그림책 쪽 사진은 수업에서만 쓰고, 저작권은 학교 안내를 따른다.
  • 학년이 끝나면 선생님이 학생과 그림책을 지운다(자동 삭제는 없음).

11.1 그림책 저작권 보호: 접근벽

그림책 쪽 사진은 저작물이라 수업에 참여하는 사람만 볼 수 있어야 한다. 그래서 관리자와 선생님이 접근할 수 있는 사용자를 직접 통제하고, 그림책이 학교 밖으로 함부로 나가지 않도록 접근벽을 여러 겹으로 세운다.

접근벽누가 통제하나내용
학급 만들기관리자학급은 관리자만 만든다. 선생님은 관리자가 만들어 준 학급으로만 들어오고, 관리자가 선생님 비밀번호를 초기화한다.
학급 코드선생님코드를 모르면 첫 화면을 넘어갈 수 없다. 코드가 알려지면 선생님이 바꾸고, 기기에 저장된 옛 코드는 바로 풀린다.
학생 허가선생님학생은 선생님이 이름을 추가하거나 가입을 승인해야 로그인할 수 있다. 가입만 해서는 들어올 수 없고, 거절하면 계정이 지워진다.
학교 안 공유선생님·관리자학교 책장은 관리자가 만든 우리 학교 학급 사이에서만 보인다. 학교 밖으로 보내는 공유 링크나 내려받기 버튼은 없다.
서버 검사앱모든 표는 RLS로 막혀 있고, 함수가 세션 토큰으로 학급·역할을 확인한 뒤에만 책 목록과 쪽을 돌려준다.
  • 정해 둘 것: 관리자는 한 학교 안에서만 운영한다. 다른 학교는 별도 설치(별도 데이터베이스)로 돌린다.
  • 남은 허점: 지금 그림책 사진 저장소(book-pages)와 미디어 저장소(book-media)는 공개 버킷이라, 사진 주소를 알면 로그인 없이 열린다. 주소는 무작위라 짐작하기 어렵지만, 주소가 밖으로 복사되면 막을 수 없다. 비공개 버킷과 기한 있는 주소(서명 URL)로 바꾸는 일을 15장에 둔다.
  • 화면 캐처·다른 기기 촬영은 기술로 막을 수 없으므로, 수업에서 그림책을 밖에 올리지 않도록 안내한다.

13. 수용 기준

  • 학급 코드는 기기에 한 번만 입력한다. 선생님이 코드를 바꾸면 새 코드를 쓰라는 안내가 뜬다.
  • 비밀번호가 틀리면 안내창만 뜨고 다시 누를 수 있다.
  • 스스로 가입한 학생은 선생님이 승인하기 전에 들어갈 수 없다.
  • 학생은 다른 학생의 카드를 옮기거나 고치거나 지울 수 없다.
  • 앞으로·뒤로는 겹친 카드가 있을 때만 눌린다. 바꾼 순서는 다시 열어도 유지된다.
  • 빈 곳을 누르면 선택이 풀리고, 다른 카드·버튼을 누르면 풀리지 않는다.
  • 「모두 부르기」를 누르면 접속 중인 학생 화면이 선생님이 보는 쪽으로 넘어간다.
  • 공개하지 않은 독후감은 친구 독후감에 보이지 않는다. 공개한 독후감을 학생이 고치면 다시 확인을 기다린다.
  • 고쳐쓰기 요청을 받은 독후감에만 「고쳐쓰기 요청」 칩이 보인다.
  • 브라우저는 표를 직접 읽거나 쓸 수 없다.
  • 확인 방법: 헤드리스 Chrome 자동 테스트 + 아이패드 실기 확인.
  • 학급 코드 없이는, 또는 선생님 허가 없는 학생 계정으로는 그림책 목록·쪽을 받을 수 없다.
  • 학교 책장에는 같은 학교 학급의 책만 보이고, 학교 밖 공유 링크·내려받기 버튼은 없다.
