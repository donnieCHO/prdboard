1. 요약

한 줄 정의: 수업 중 폰을 볼 수 없는 담임교사를 위한 안드로이드 앱이다. 쌓인 메신저·문자 알림을 정한 시각에 "누가 · 무엇을 · 언제까지" 부탁했는지로 정리해 준다. 정리는 폰 안의 AI(Gemma 4)가 하고, 앱에는 인터넷 권한이 없어 학부모·학생 대화가 폰 밖으로 나가지 않는다.

예시: 오후에 쌓인 알림 37건이 답장할 연락 2건, 대화방 요점, 건수 한 줄로 줄어든다.

목표

#목표뜻
G1놓치지 않기쉬는 시간 몇 분 안에, 꼭 답해야 할 연락과 마감 있는 부탁을 모두 찾는다
G2덜 보기광고·정기 알림·잡담을 거르고, 단톡방 수십 건을 사람별 한두 줄로 줄인다
G3밖으로 내보내지 않기서버·계정·인터넷 없이 폰 안에서만 처리한다

하지 않는 것

  • 자동으로 답장 보내기
  • 클라우드 동기화·계정
  • 아이폰 판
  • 🆕 메신저 앱 안의 대화 읽기: 알림으로 들어온 내용만 다룬다. 앱을 열어 대화 목록을 읽지 않는다.
  • 🆕 학생·학부모 쪽 앱: 교사 한 사람이 쓰는 도구다.

2. 문제

담임교사에게 필요한 것은 알림을 더 빨리 받는 것이 아니다. 수업에 집중하면서도 꼭 답할 연락을 놓치지 않는 것이다.

교사의 현실

  • 연락이 흩어져 온다: 학부모 카톡·문자, 동학년·학년부 단톡, 하이클래스·학교종이·클래스팅 같은 학급 소통 앱, 업무 메일이 한 폰으로 들어온다.
  • 수업 중에는 폰을 못 본다: 하루 5~6교시 동안 쌓인 알림을 쉬는 시간 10분에 하나씩 열어 보기 어렵다.
  • 중요한 한 줄이 묻힌다: 단톡 공지 끝의 "각 반 금요일까지 제출", 학부모의 "내일 조퇴해도 될까요?"가 광고·배송·잡담 사이에 있다.
  • 퇴근 뒤에도 알림이 온다: 계속 확인하거나, 놓칠 걱정을 안고 알림을 끄는 수밖에 없다.

지금 도구의 한계

지금 하는 방법한계
그때그때 확인수업이 끊기고, 다 읽어야 중요한 것을 안다
방해 금지·알림 끄기조용해지지만 답해야 할 연락도 함께 묻힌다
폰 기본 알림 요약(클라우드 AI)학부모·학생 이야기가 폰 밖 서버로 나간다
메신저 앱마다의 요약 기능그 앱 안에서만 돌고, 앱을 넘어 사람별로 묶지 못한다

쌤톡스의 해법

알림은 조용히 모아 두고, 정한 시각에 한 장으로 보여 준다. 순서는 ① 답장할 연락 → ② 대화방 요점 → ③ 광고·정기 알림 건수다. 전화·알람·재난 문자는 모으지 않고 평소처럼 울린다.

4. 🆕 용어

용어뜻
모아서 알림메시지 알림을 상태바에서 숨기고 앱 안에 쌓아 두는 상태. 스위치 하나로 켜고 끈다
정한 시각 요약사용자가 정한 시각(또는 N시간마다)에 쌓인 알림을 한 장으로 정리해 보여 주는 것
미리 요약정한 시각 전, 화면이 꺼져 있는 동안 미리 AI 요약을 해 두는 것
답장할 연락물음·부탁·마감이 담겨 교사의 응답이 필요한 메시지. 요약 맨 위에 온다
대화방 요점대화방마다 "누가 무엇을 부탁했는지" 한두 줄
건수만날씨·봇·정기 알림처럼 내용 대신 "○○ 알림 N건"으로만 표시하는 것
사람 묶음앱이 달라도 같은 사람이 보낸 알림을 하나로 묶는 것. 학부모 명부를 기준으로 한다
간단 정리발열·배터리 부족 때 AI 없이 앱 규칙만으로 만드는 요약
할 일 중심 요약대화방별 요점 대신 할 일·바뀐 것·일정만 마감 순으로 보여 주는 실험 방식

5. 기능 요구사항

핵심 흐름은 모으기 → 거르기 → 요약 → 정한 시각에 알리기 네 단계다. P0은 이 흐름을 만드는 기능이고, P1·P2는 교사 업무에 맞추거나 편하게 하는 기능이다.

P0: 핵심 흐름 (모두 완료)

기능하는 일🆕 완료 조건
알림 모으기카톡·문자·학급 소통 앱 알림을 폰 안에 저장하고, 모으는 동안 상태바에서 숨긴다대상 앱 알림이 하나도 빠짐없이 저장되고 상태바에 남지 않는다
폰 안 AI 요약Gemma 4(E4B/E2B)가 대화방별로 "누가 무엇을 부탁했는지" 한 줄로 정리한다채점 세트에서 꼭 들어갈 말 21/21, 지어낸 숫자 0
정한 시각 요약 알림여러 시각 또는 N시간마다 실행한다. 잠금·재부팅 뒤에도 정확하다잠금·재부팅·절전 상태에서도 정한 시각 ±1분 안에 알림이 뜬다 (허용 오차 확인 필요)
답장할 연락 맨 위물음·부탁·마감을 급한 순으로, 말한 사람 이름과 함께 보여 준다채점 세트의 답장 필요 연락이 모두 맨 위 칸에 있다
예외 처리전화·알람·재난 문자는 숨기지 않는다. 인증번호는 저장하지 않는다예외 알림이 평소대로 울리고, DB에 인증번호가 남지 않는다
인터넷 권한 없음APK에서 인터넷 권한을 뺀다배포 APK의 매니페스트에 INTERNET 권한이 없다

P1: 교사 업무 맞춤·안정성

기능하는 일상태
광고·정기 알림 거르기광고는 거르고, 날씨·봇 같은 알림은 건수만 남긴다완료
👪 학부모 명부·👥 사람 묶음이름만 넣으면 어느 앱에서 왔든 같은 사람으로 묶는다완료
📌 할 일·마감"금요일까지", "3시 회의"에서 날짜를 뽑아 자동 등록한다완료
⚡ 미리 요약화면이 꺼진 동안 미리 정리해 정한 시각에 바로 보여 준다완료
발열·배터리 보호폰이 뜨겁거나 배터리 15% 이하면 AI 없이 간단히 정리한다완료

✅ 할 일 중심 요약모든 방에서 할 일·바뀐 것·일정만 마감 순으로 보여 준다실험(기본 꺼짐)

6. 🆕 알림 처리 규칙

들어온 알림은 아래 다섯 갈래 중 하나로 처리한다. 위에서부터 먼저 맞는 규칙을 적용한다.

순서갈래예처리
1절대 숨기지 않음전화, 알람, 재난 문자모으지 않고 평소처럼 울린다
2저장 안 함인증번호 문자평소처럼 보여 주고, 앱에 저장하지 않는다
3거름광고요약에서 뺀다 (건수 표시 여부 확인 필요)
4건수만날씨, 봇, 배송, 정기 알림"○○ 알림 N건"으로만 표시한다
5요약 대상학부모·동료·단톡 메시지AI 요약에 넣는다. 답장·마감은 규칙으로 한 번 더 확인한다

답장할 연락 판단 기준

  • 물음: 물음표, "~될까요", "~가능한가요" 같은 묻는 말
  • 부탁: "~해 주세요", "~부탁드립니다", "각 반 ~"
  • 마감: 날짜·요일·시각이 함께 있는 부탁

정렬은 마감이 가까운 것 → 학부모 명부에 있는 사람 → 받은 시각 순이다. (정렬 기준 확인 필요)

8. 비기능 요구사항·원칙

학부모·학생 이야기를 다루는 앱이므로 편리함보다 "폰 밖으로 나가지 않기"가 우선이다.

영역원칙
개인정보인터넷 권한, 계정, 광고·분석 도구가 없다. 모델은 처음 한 번 브라우저로 받아 파일로 넣는다
데이터 보관받은 알림은 기본 7일 뒤 지운다. 백업은 AES-256으로 잠그고 메시지 내용은 넣지 않는다
모델Gemma 4로 고정한다. 한국어가 자연스럽고 LiteRT-LM과 잘 맞는다. 램 8GB 이상은 E4B(3.7GB), 6GB는 E2B(2.6GB)를 쓴다. 모델을 바꾸지 않고 최적화로 풀어간다 (2026-11-22 결정)
연산 장치GPU만 쓰고, GPU를 못 여는 폰에서만 CPU로 대신한다. NPU는 칩마다 따로 변환한 모델이 필요해서 쓰지 않는다 (2026-11-23 결정)
기기 부담AI 호출 수를 줄인다. 미리 요약은 화면이 꺼졌을 때만 하고, 끝나면 모델을 메모리에서 내린다. 뜨겁거나 배터리가 적으면 AI를 켜지 않는다
정확성원문에 없는 숫자가 나오면 버리고 다시 묻는다. AI가 답장·마감을 빠뜨려도 앱 규칙으로 다시 넣는다
통제권답장은 초안까지만 쓴다. 보내기는 교사가 누른다
