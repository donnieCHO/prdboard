생기부 점검 웹앱 PRD

2026-11-25 생기부 연수에서 쓴 엑셀 매크로 「학교생활기록부 점검 도우미 ver.7」의 기능을 웹 앱으로 옮기기 위한 제품 요구사항 문서(PRD, Product Requirements Document) 초안이다. 기능 목록의 근거는 원본 구조 변환본 raw/생기부연수/2026-11-25 2026. 학교생활기록부 점검 도우미 ver.7(중학교용)_2026.6.16.md이다.

초안 상태 큰 방향은 모두 정했다 (2026-11-25). 자세한 것은 맨 아래 「9. 정한 것」. 남은 일은 나이스 파일 구조 확인, 엑셀 규칙 두 개 확인, 원작자 허락이다 (「할 일」).

1. 배경과 문제

  • 엑셀 도구는 기능이 풍부하지만 매크로 포함 엑셀(.xlsm)이라 MS 엑셀에서만 돌아간다. 매크로 보안 경고, 한셀·맥·웹 엑셀에서 안 됨. (2026-11-25 학교생활기록부 점검 도우미 ver.7)
  • 같은 항목 파일을 두 개 고르면 앞 자료를 덮어써서 한 번에 한 반씩만 점검할 수 있다.
  • "셀병합 등의 이유로 정상 작동하지 않을 수 있으니 원본 파일 백업 필수" 안내가 있을 만큼 깨지기 쉽다.
  • 버튼이 시트마다 흩어져 있고(키워드 표시 26개 등), 결과를 칸 색깔로만 보여 줘서 처음 쓰는 교사가 무엇을 고쳐야 할지 한눈에 보기 어렵다. (추정: 연수 진행 경험 기준, 확인 필요)
  • 사용 제한 날짜(2045-02-28)가 걸려 있다.

2. 목표

  1. 엑셀 도구의 점검 기능을 빠짐없이 웹에서 쓸 수 있다.
  2. 설치·매크로 허용 없이 학교 PC 브라우저(크롬·엣지·웨일)만으로 쓴다.
  3. 학생 자료는 선생님 PC 밖으로 나가지 않는다.
  4. 여러 반·학년을 한 번에 올리고, "고칠 것 목록" 형태로 결과를 본다.

하지 않을 것 (범위 밖)

  • 나이스에 직접 접속하거나 나이스 자료를 고쳐 쓰는 일. 고치기는 선생님이 나이스에서 한다.
  • 서버에 학생 자료 저장, 여러 교사 동시 편집, 로그인.
  • AI로 문장을 고쳐 주는 기능 (학생 글을 외부 AI로 보내게 되므로). → 별도 도구 AI 활용 학교생활기록부 작성
  • 맞춤법 검사. 엑셀 도구의 「맞춤법」(MS 맞춤법 사전)은 옮기지 않는다. 맞춤법은 다른 도구에서 한다. (2026-11-25 결정)

3. 사용자

사용자하는 일
담임·교과 교사자기 반·과목 자료를 올려 점검 결과를 보고 나이스에서 고친다
생기부 담당(정보부장)학년 전체를 모아 점검, 기준값(키워드·수상명 등)을 학교에 맞게 정해 교사들에게 나눠 준다
  • 이 학교 교사 19명 규모 연수에서 쓸 수 있어야 한다. (2026-11-25 생기부 연수)
  • 컴퓨터에 익숙하지 않은 교사도 안내만 따라 하면 쓸 수 있어야 한다.

4. 사용 흐름

  1. 나이스에서 항목별 엑셀을 내려받는다 (학적·출결·수상·봉사·독서·자유학기·창체·세특·행특).
  2. 웹 앱에 파일을 끌어다 놓는다 (여러 개, 여러 반 한꺼번에).
  3. 앱이 파일마다 항목을 알아보고 「불러온 자료」 표로 보여 준다 (항목, 학년·반, 학생 수).
  4. 「점검 결과」 대시보드에서 항목별 점검 건수를 본다.
  5. 항목을 눌러 들어가면 학생별로 걸린 내용이 빨간 표시와 걸린 이유와 함께 나온다.
  6. 나이스에서 고친 뒤 「확인」을 체크한다.
  7. 필요하면 결과를 엑셀로 내려받는다. 끝나면 「모두 지우기」.

6. 개인정보·보안 요구사항

생기부 자료는 학생 이름·수상·봉사·결석 사유가 든 민감한 자료다. (2026-11-25 학교생활기록부 점검 도우미 ver.7, 정보보안 업무)

  • N1 파일은 브라우저 안에서만 읽고 처리한다. 앱은 학생 자료를 어디로도 보내지 않는다 (서버 없음, 분석 도구·외부 글꼴·광고 없음).
  • N2 학생 자료와 점검 결과·「확인」 표시는 브라우저에 저장하지 않는다. 탭을 닫으면 사라진다. 브라우저 저장소에는 설정만 남긴다. (2026-11-25 결정)
    • 자료가 있는 채로 탭을 닫거나 새로 고치면 "불러온 자료와 확인 표시가 사라집니다" 경고를 띄운다.
    • 다시 보려면 나이스 파일을 다시 올린다.
  • N3 화면에 "이 앱은 자료를 외부로 보내지 않습니다"를 적고, 인터넷이 끊겨도 동작해야 한다 (확인 방법이 되기도 함).
  • N4 외부로 자료를 보내는 기능은 두지 않는다. (맞춤법 사이트 연결도 넣지 않기로 함)
  • N6 웹 주소에 올려도 서버는 앱 파일만 내려 준다. 파일 처리는 모두 선생님 브라우저 안에서 한다.
  • N5 개발·시험·연수 시연에는 가상 학생 자료만 쓴다. 실제 나이스 파일은 저장소(깃)에 넣지 않는다 (CLAUDE.md 「꼭 지킬 규칙」).

7. 비기능 요구사항

  • 학교 PC의 크롬·엣지·웨일 최신판에서 동작. 노트북 화면(1366×768)에서도 쓸 만해야 한다.
  • 한 학년(약 100명, 9개 항목) 자료를 불러와 점검하는 데 10초 안. (추정 목표, 실제 규모 확인 필요)
  • 버튼 글자는 쉬운 우리말로. 각 화면 맨 위에 "무엇을 하는 화면인지" 한 줄 안내.
  • 배포: 웹 주소에 올린다 (정적 웹사이트, 예: GitHub Pages). 선생님들께는 주소만 알려 드리고, 고치면 모두에게 바로 반영된다. (2026-11-25 결정)
    • 학교 PC에서 그 주소가 막히지 않는지 먼저 확인한다.
    • 엑셀 읽기 라이브러리(SheetJS 등)는 앱과 함께 올려, 다른 사이트에서 불러오지 않는다 (N1).
  • 원작자 표기: 앱의 「만든 사람·출처」에 "점검 규칙 출처: 학교생활기록부 점검 도우미 ver.7 (전라남도교육청 김중곤)"을 적는다. 공개 전에 원작자에게 허락을 받는다. (2026-11-25 결정)
